Privacy policy

Last updated: October 3, 2026

In short: Pickets doesn't collect, store or share any personal information. It has no accounts, ads, analytics or telemetry. Its only network connection is an optional check for new versions on GitHub. Everything else stays on your PC.

This policy covers the Pickets desktop application for Windows and this website. Pickets is an open-source project maintained by Christopher Fennell; its source code is public at github.com/chrisdfennell/Pickets, so anything described here can be checked against the code.

What Pickets sends over the network

Pickets connects to the internet for one purpose only: checking for updates.

  • About 10 seconds after it starts, and then once a day, it asks GitHub's public API (api.github.com) for the latest Pickets release. The request identifies itself as Pickets-Updater/ followed by the installed version number. It contains nothing about you, your PC or your files.
  • If a newer version exists and you choose Install now, the installer is downloaded from GitHub and checked against the checksum GitHub publishes for it.
  • You can turn automatic checks off under Settings → Updates → Check for updates automatically. With it off, Pickets only connects when you choose Settings → Updates → Check now (or Check for Updates… in the tray menu).

As with any website, GitHub receives your IP address and the request when these checks happen. GitHub's handling of that information is covered by the GitHub General Privacy Statement. Pickets itself does not receive or keep any of it.

Pickets sends nothing else: no usage statistics, no crash reports, no information about your desktop or files.

What Pickets stores on your PC

Everything Pickets keeps stays on your computer, in your user profile:

WhatWhereWhy
Settings and fence layout (names, positions, which desktop items each fence shows, colors) %AppData%\Pickets\config.json and a backup, config.json.bak To restore your fences the next time it starts
Saved layouts %AppData%\Pickets\layouts\ So you can restore an earlier layout
Error log (technical details of unexpected errors, which can include file paths) %AppData%\Pickets\error.log To help diagnose problems. It's never sent anywhere; you can choose to share it when reporting a bug.
A "start with Windows" entry, only if you turn that setting on The current user's Run key in the Windows registry To start Pickets when you sign in

While it runs, Pickets also reads your desktop folders and their icons and thumbnails (through Windows), and hides the normal desktop icons, restoring them when it exits. None of this leaves your PC.

Versions released before the rename used the folder %AppData%\OpenFences. The first time Pickets starts, it moves that folder to %AppData%\Pickets and updates the "start with Windows" entry, so your fences carry over.

To remove all of it: quit Pickets, uninstall it, and delete the %AppData%\Pickets folder.

This website

This website is a static site hosted on GitHub Pages. It uses no cookies, no analytics and no tracking scripts, and loads nothing from third-party services. GitHub, as the host, may log technical information such as IP addresses for security and operations, as described in the GitHub General Privacy Statement.

Download links lead to GitHub Releases, which is also covered by GitHub's privacy statement.

Children

Pickets doesn't collect personal information from anyone, including children.

Changes to this policy

If Pickets ever starts handling data differently, this page will be updated before that release, and the change will be described in the release notes. The full history of this page is public in the project's repository.
