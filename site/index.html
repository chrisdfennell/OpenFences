Your desktop, sorted into fences

OpenFences is a free, open-source app for Windows 10 and 11 that groups your desktop icons into movable, resizable fences, so the clutter turns into something you can actually find things in.

Download for Windows View the source

Free and open source (MIT) · x64 and ARM64 · Updates itself

What it does

Your files stay exactly where they are on your desktop. A fence only decides where each item is shown, and quitting OpenFences brings your normal desktop icons back.

▦

Fences for your real desktop items

Every desktop item lives in exactly one fence. Drag tiles between fences, into Explorer or into any app.

⚡

Sorts itself

One click sorts your desktop into Apps, Documents and System. Rules send new files to the right fence automatically.

🗁

Folder portals

Show any folder as a live fence and browse into its subfolders without opening Explorer.

⌕

Search everything

Press Ctrl+Alt+F to find any item in any fence. Ctrl+Alt+H hides or shows them all.

⇕

Roll up and peek

Double-click a title to roll a fence up; rest the mouse on it to peek inside.

◧

Snap, style, lock

Fences snap to screen edges and each other. Pick colors, frosted glass and title sizes, or lock a fence in place.

▣

Multi-monitor aware

Each fence remembers where it goes for every monitor setup, and is never left off-screen when you undock.

↺

Layouts you can undo

Save and restore whole layouts. A snapshot is taken automatically before big changes.

☰

Feels like Windows

Windows' own right-click menu, picture and video thumbnails, rename in place and full keyboard support.

Pictures and videos behind your icons

Give any fence a picture or a looping video background. It fades with the fence's transparency, can be darkened so labels stay readable, and pauses while the fence is hidden or rolled up.

Find anything in a keystroke

Search lists matches from every fence, brings the fences to the front and fades out everything that doesn't match. Press Enter to open.

Download

Get the latest version from the releases page. After that, OpenFences checks for new versions itself and installs them on request.

Installer (recommended)

OpenFences-x64.msi for most PCs, OpenFences-arm64.msi for ARM devices such as Snapdragon laptops.

Portable

OpenFences-x64-portable.zip or OpenFences-arm64-portable.zip: unzip and run OpenFences.exe.

Build it yourself

Install the .NET 8 SDK, clone the repository and run dotnet run --project OpenFences.

Requires Windows 10 or 11. No .NET installation needed for the installer or the portable version.

Open source

OpenFences is developed in the open on GitHub under the MIT license. Every release is built from a tagged commit in that repository by GitHub Actions, after the automated tests pass.

Code signing policy

Only official releases of OpenFences are signed. A release is signed only when it is built by the project's GitHub Actions workflow from a tagged commit in the official repository, after the automated tests pass. Locally built copies and forks are not signed with the project's certificate.

Committers and reviewers

Christopher Fennell (maintainer). Outside contributions arrive as pull requests and are reviewed by the maintainer before merging.

Approvers

Christopher Fennell approves each release before it is signed.

What gets signed

OpenFences.exe, OpenFences.dll and the .msi installers in each release.

See the privacy policy for exactly what OpenFences sends over the network (in short: only update checks to GitHub, which you can turn off).
